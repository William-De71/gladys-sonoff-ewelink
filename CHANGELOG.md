## [0.1.0] - 2026-10-12

### Added

- Local network control of Sonoff / eWeLink devices: mDNS discovery relayed by
  Gladys, encrypted (AES-128) and DIY-mode LAN protocol, state polling and
  commands in unicast.
- Optional eWeLink cloud through the user's own developer application: OAuth
  2.0 sign-in (or e-mail and password), device list with the encryption keys,
  real-time WebSocket updates, cloud fallback and remote control.
- "Prefer the local connection" toggle and per-device transport badges, with a
  degraded state when a device falls back to the cloud.
- Over 110 device models: switches and multi-channel modules, power meters
  (POW, POWR2/R3, S40, S60, DualR3, SPM), TH thermostats, lights (D1, B02, B05,
  L1, L3, Zigbee), fans (iFan), covers and garage doors, Wi-Fi and Zigbee
  sensors, TRVZB radiator valve, NSPanel, SNZB-09P siren, water valves, RF
  Bridge 433.
- Scene triggers: button pressed, RF code received, device online/offline,
  cloud status changed.
- Scene actions: send an RF code, send a raw eWeLink command, rescan the
  devices.
- Dashboard widgets: Sonoff network status, energy monitor, RF remote.
- Configuration actions: add or remove a device by hand (DIY mode, known
  encryption key), test the connection.
- User documentation and README in English, French, German and Spanish.
